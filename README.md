## Featured Projects

### Blogology — Full-Stack Editorial & AI Publishing Platform

Production blogging platform with Next.js 16, Express.js, Prisma ORM, and PostgreSQL. Public routes use pure SSR with `"use cache"` / `cacheTag` for SEO; protected routes use TanStack Query via Route Handlers and Server Actions. Features a BlockNote rich-text editor, Google Gemini AI streaming (SSE), Redis session caching with distributed rate limiting, and Stripe Checkout with verified webhooks. E2E tested with Playwright.

**Live Demo:** https://blogology-v2-frontend.vercel.app
**Repository:** https://github.com/Adi-01/Blogology-v2-frontend

---

### FinFlow — AI Expense & Budget Tracker

Full-stack budgeting platform with monthly scoping, automated rollover, real-time cross-device sync via SSE and Redis Pub/Sub, Google AI spending analysis with model fallback chaining, and optimistic UI updates backed by TanStack Query.

**Live Demo:** https://fin-flow-frontend-zeta.vercel.app
**Repository:** https://github.com/Adi-01/FinFlow-frontend

---

### ByteBox — Cloud File Storage

Cloud storage platform supporting secure file uploads, granular access sharing, trash recovery, global search, and per-user storage quotas. Built with Next.js, Django REST Framework, and Appwrite with Server Actions and strategic cache invalidation.

**Live Demo:** https://bytebox-appwrite.vercel.app
**Repository:** https://github.com/Adi-01/bytebox-appwrite
