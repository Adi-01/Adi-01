# ⭐ Featured Projects

## 💰 FinFlow — AI Expense & Budget Tracker

Full-stack personal finance and monthly budgeting platform with real-time cross-device sync and AI spending insights.

**Tech Stack:** `Next.js 16` • `TypeScript` • `Node.js` • `Express.js` • `PostgreSQL` • `Redis` • `TanStack Query` • `Google AI`

### Features
- Monthly-scoped budgeting with dynamic balance calculation and automated positive rollover
- Optimistic UI mutations with **TanStack Query** and automatic snapshot rollbacks
- Real-time multi-session sync via **Server-Sent Events (SSE)** and **Redis** Pub/Sub
- Multi-tier **Redis** caching, active session tracking, and sliding-window API rate limiting
- **Google AI** integration with fallback model chaining to classify spending archetypes and generate financial reflection reports with interactive chat

🔗 **Live Demo:** https://fin-flow-frontend-zeta.vercel.app  
🔗 **Repository:** https://github.com/Adi-01/FinFlow-frontend

---

## 📦 ByteBox — Cloud File Storage Platform

Full-stack cloud file storage web application with granular sharing, storage quotas, and fast client caching.

**Tech Stack:** `Next.js 16` • `TypeScript` • `Django REST Framework` • `Appwrite` • `TanStack Query`

### Features
- Secure multipart file uploads, trash recovery, and per-user storage quota enforcement
- Granular public/private file sharing and global search
- Modular backend architecture originally designed in **Django REST Framework** and migrated to **Appwrite** to streamline infrastructure
- **Next.js Server Actions** and **TanStack Query** cache invalidation for low-latency interactions

🔗 **Live Demo:** https://bytebox-appwrite.vercel.app  
🔗 **Repository:** https://github.com/Adi-01/bytebox-appwrite
